Design system

Dataflow

Every surface is a node, every relationship an edge. Colour splits upstream (cold cyan) from downstream (hot amber); neutrals carry a cyan bias so they read as chosen, not inherited. The three prototypes inline a copy of these tokens; the React app imports dataflow.css directly.
